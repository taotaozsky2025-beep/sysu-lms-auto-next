# 中大 LMS 视频自动连播

一个面向中山大学 LMS（`lms.sysu.edu.cn`）的轻量 Chrome 扩展。视频实际播放结束后，扩展会等待 3 秒，让平台保存观看进度，然后自动进入下一课程活动并尝试播放。

## 功能

- 监听 HTML5 视频的真实结束事件。
- 自动识别 Moodle 风格的“下一活动”链接。
- 下一页加载后尝试自动播放；若浏览器阻止有声自动播放，会尝试静音播放并提示。
- 页面右下角提供“自动连播”开关。
- 支持视频位于同源 iframe 的页面。

本扩展不修改、伪造或加速课程观看进度，也不提供拖动或跳过未观看内容的功能。

## 安装

1. 下载源码并解压。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的项目文件夹。
6. 刷新 LMS 视频页面。

成功加载后，页面右下角会显示“自动连播：开”。

## 隐私与权限

- 扩展仅匹配 `https://lms.sysu.edu.cn/*`。
- 不声明额外 Chrome 权限。
- 不读取账号密码、Cookie 或浏览器历史。
- 不向第三方服务器发送数据。

## 兼容性

- Chrome Manifest V3。
- 依赖页面存在可访问的 HTML5 `<video>` 元素及 Moodle 风格活动导航。
- LMS 页面结构更新后，可能需要同步调整选择器。
